# Nexus-Shell
The Google Nexus line of smartphones (and tablets) was once considered Googles reference implementation of an Android smartphones. Now they are one of the currently 308 projects killed by Google. One day even Google's new Googlebook OS might be deprecated. On an unrelated note, this is supposed to be a nice desktop shell to be used alongside your favourite window manager / compositor. I once tried vibecoding one, but that felt bad so this one is made by hand (for better or worse).
